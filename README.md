L.A. Noire Save File Editor (HTML)

A lightweight browser-based save file editor for L.A. Noire. This tool allows you to open and modify your game save directly in your web browser without installing any additional software.

Features

-Upload and parse L.A. Noire save files
-View key progress data (cases, desk progression, stats, etc.)
-Edit selected save values
-Download the modified save file
-Runs completely in HTML/JavaScript (no server required)

Usage

-Download or clone the repository
-Open index.html in your browser
-Upload your L.A. Noire save file
-Edit the values you want
-Export the modified save

Disclaimer
Use at your own risk. Editing save files can corrupt saves or affect game progression. Always create a backup before modifying any files.
